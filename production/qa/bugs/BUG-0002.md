**Reporter**: Player screenshot

## Classification
- **Category**: Visual
- **System**: World content / streamed desert chunks
- **Frequency**: Always in affected chunk scenes
- **Regression**: Unknown

## Environment
- **Build**: Unity 2022.3.62f3c1, WebGL play mode
- **Platform**: macOS editor screenshot, WebGL target
- **Scene/Level**: Main_Persistent with streamed Desert_Chunk scenes
- **Game State**: Runtime chunk streaming active in desert terrain

## Reproduction Steps
**Preconditions**: Streamed desert chunks are enabled.

1. Enter play mode in `Main_Persistent`.
2. Move through or face toward streamed desert terrain chunks.
3. Watch the terrain surface as chunks activate.

**Expected Result**: Streamed desert chunks contain only intended terrain, roads, and gameplay-relevant content.
**Actual Result**: Non-desert prefab instances such as `Kelp`, `sofa`, `Flowerpot`, and building prefabs appear in chunk scenes.

## Technical Context
- **Likely affected files**:
  - `Assets/Scenes/Chunks/*.unity`
  - `Assets/Scenes/terrain/Desert_Chunk_-1_-6.prefab`
- **Related systems**: World streaming, chunk scene authoring, generated terrain content
- **Possible root cause**: Test/sample props were serialized into generated or streamed chunk scenes and not filtered before runtime.

## Evidence
- **Logs**: No error log required; issue is visible in play mode.
- **Visual**: Screenshot shows a green `Kelp` object rendered on the desert terrain surface.
