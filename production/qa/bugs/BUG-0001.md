# Bug Report

## Summary
**Title**: Predictive distant chunks render as vertical terrain sheets while loading
**ID**: BUG-0001
**Severity**: S2-Major
**Priority**: P1-Immediate
**Status**: Open
**Reported**: 2026-07-08
**Reporter**: Player screenshot

## Classification
- **Category**: Visual
- **System**: World streaming / desert terrain chunks
- **Frequency**: Often when forward predictive chunks load before adjacent chunks
- **Regression**: Unknown

## Environment
- **Build**: Unity 2022.3.62f3c1, WebGL play mode
- **Platform**: macOS editor screenshot, WebGL target
- **Scene/Level**: Main_Persistent with streamed Desert_Chunk scenes
- **Game State**: Runtime chunk streaming active at night

## Reproduction Steps
**Preconditions**: `WorldStreamer.useGridStreaming` is enabled and predictive forward streaming is active.

1. Enter play mode in `Main_Persistent`.
2. Move or face toward unloaded desert chunks quickly enough for forward predictive streaming to enqueue chunks beyond the base grid.
3. Watch the distant horizon as those chunks activate.

**Expected Result**: Predictive chunks may preload, but terrain only becomes visible once it is part of the contiguous visible chunk area.
**Actual Result**: Isolated distant chunks can activate visually before surrounding chunks, exposing high terrain skirts as large vertical sheets or floating caps.

## Technical Context
- **Likely affected files**:
  - `Assets/Scripts/Environment/WorldStreamer.cs`
  - `Assets/Scripts/Environment/DesertTerrainChunk.cs`
- **Related systems**: Saved desert chunk meshes, snow layer, road overlay, chunk collider activation
- **Possible root cause**: The streamer used one requested chunk set for both preloading and visual activation. Forward-only predictive chunks could render before they had adjacent visual support, making baked skirts and high-elevation saved mesh edges visible.

## Evidence
- **Logs**: No error log required to reproduce; visual artifact is visible in play mode.
- **Visual**: Screenshot shows distant terrain loading as tall vertical sheets against the sky.

## Related Issues
- None yet.

## Notes
Fix should keep predictive loading for performance, but decouple preload state from renderer/collider readiness.
